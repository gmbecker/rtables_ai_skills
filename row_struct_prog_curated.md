# Curated Row Structure Programming Reference (`row_struct_prog_curated.md`)

This curated document collects canonical code-rendered table pairs isolating the **row faceting structure**, deduplicated by *structural archetype* from the full 580-pair dataset (`row_struct_prog.md`). Column structure is removed (every table has the single default `all obs` column) and all analysis / content functions are replaced by the shared dummy functions below, so only the shape of the row tree matters.

> [!IMPORTANT]
> **Tabulation Model Rules:**
> - **Column structure** is implemented via zero or more calls to the `split_cols_by*` family of functions; nothing else impacts column structure.
> - **Row faceting structure** (up to but not including individual rows) is implemented via zero or more calls to the `split_rows_by*` family.
> - **Individual rows** are implemented via one or more calls to the `analyze*` family of functions.
> - **Facet labels** are converted into group summary rows via a single call to `summarize_row_groups` directly after the relevant `split_rows_by*` function call.
> - `split_rows_by(..., child_labels = "visible")` in combination with a following `summarize_row_groups` is only used when the row(s) generated by `summarize_row_groups` do **not** act in the same capacity as the default label row for a facet (represented here using `cfun = dummy_n_rows_factory(k)` rather than `cfun = dummy_one_row`).

### Shared Dummy Function Definitions (evaluate before any entry)

Every entry is reproducible by evaluating this block, then the entry's **Setup** block, then its **Core layout** block, in a fresh R session.

```r
dummy_one_row <- function(x, label_str = NULL, labelstr = label_str, ...) {
  if (is.null(label_str) && !is.null(labelstr) && nzchar(labelstr)) label_str <- labelstr
  if (is.null(label_str) || !nzchar(label_str))
    label <- "label"
  else
    label <- label_str
  rcell("-", format = "xx", label = label)
}

dummy_n_rows_factory <- function(n) {
  function(x, label_str = NULL, labelstr = label_str, ...) {
    labs <- if (n <= 26) letters[seq_len(n)] else paste0("r", seq_len(n))
    cells <- lapply(seq_len(n), function(i) rcell("-", format = "xx", label = labs[i]))
    names(cells) <- labs
    in_rows(.list = cells, .labels = labs)
  }
}
```

### Curation Summary:
- **Total curated pairs**: 115 (108 standard `rtables`, 7 requiring `junco`), from 580 extracted pairs.
- **Archetype deduplication**: 114 entries contain `split_rows_by*` calls and each represents a distinct structural archetype; exactly **1** entry without any `split_rows_by*` call is retained (the canonical no-split stacked analysis: `analyze(1var) > analyze(1var)`).
- **Archetype definition** (shown on each entry as `Archetype:`): the ordered sequence of layout calls after `basic_table()` with *data-specific* details abstracted away. Variable names, labels, `split_label`, `labels_var`, `format`, `cuts`/`cutlabels`, `section_div`, `indent_mod`, `table_names`, `afun`/`cfun`, and the number of dummy rows are ignored; arguments left at their defaults (`nested = TRUE`, `child_labels = "default"`, `label_pos = "hidden"`, `show_labels = "default"`, `page_by = FALSE`) are ignored. What *is* retained: call order and nesting, `summarize_row_groups` placement, `nested = FALSE`, `at_sibling`, `page_by`, `child_labels`, `label_pos`, `show_labels`, single- vs multi-variable `analyze`, and the **kind** of `split_fun` (`drop_split_levels`, `keep_split_levels`, `trim_levels_in_group`, `make_split_fun(<component kinds>)`, junco split-fun constructors, or `custom` for user-defined functions). For example `split_rows_by("SEX") > split_rows_by("RACE") > analyze(...)` and `split_rows_by("COUNTRY") > split_rows_by("BMRKR2") > analyze(...)` both map to `split_rows_by() > split_rows_by() > analyze(1var)`.
- **Representative choice**: within each archetype, the entry requiring no `junco` is preferred, then rtables vignettes over tests, then the smallest setup + layout code.
- **Reproducibility**: each Setup block was reduced to the minimal backward dependency slice of the core layout (unused objects, post-build table manipulation, and test assertions removed; test fake-data generators inlined where needed). Every entry was re-executed in its own fresh `Rscript` process with only the shared dummy block, and the rendered output below is exactly what that execution produces.

top_k_plus_other <- function(k = 3, other_label = "Other System Organ Classes") {
  make_split_fun(post = list(function(ret, spl, fulldf) {
    fac_names <- names(ret$values)
    fac_ns <- vapply(ret$datasplit, NROW, 1L)
